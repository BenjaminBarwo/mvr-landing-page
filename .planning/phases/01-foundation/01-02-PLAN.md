  <action>
    1. Create `src/app/api/webhooks/stripe/route.ts` following RESEARCH.md Pattern 5 exactly:
       - Import `Stripe` from `stripe` and `NextRequest`, `NextResponse` from `next/server`
       - Instantiate Stripe client with `STRIPE_SECRET_KEY` env var
       - Get webhook secret from `STRIPE_WEBHOOK_SECRET` env var
       - Export `POST` function:
         a. Read raw body with `await request.text()` — CRITICAL: do NOT use `request.json()` (destroys signature verification)
         b. Extract `stripe-signature` header
         c. If missing signature, return 400 with `{ error: 'Missing stripe-signature' }`
         d. Try `stripe.webhooks.constructEvent(body, signature, webhookSecret)`
         e. On verification failure, return 400 with descriptive error
         f. Switch on `event.type`:
            - `payment_intent.succeeded`: comment stub "Phase 4: update application status, trigger confirmation email"
            - `payment_intent.payment_failed`: comment stub "Phase 4: update payment status"
            - `checkout.session.completed`: comment stub "Phase 4: alternative payment flow"
            - default: log unhandled event type, continue
         g. Return 200 with `{ received: true }`

    2. IMPORTANT: Do NOT export a body parser config — Next.js Route Handlers do not auto-parse request bodies. This is different from Pages Router API routes.

    3. Exclude the webhook route from middleware auth check — it should NOT require admin auth. Verify that the middleware matcher `/admin/:path*` does NOT match `/api/webhooks/stripe`. (It shouldn't by default, but verify.)
  </action>

    - `curl -X POST http://localhost:3000/api/webhooks/stripe -H "stripe-signature: invalid"` returns 400 (verification failed)
    - The middleware matcher does not intercept `/api/webhooks/stripe` requests
  </verify>
