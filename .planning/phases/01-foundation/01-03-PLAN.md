</objective>

  <files>

  <action>
    1. Create `scripts/seed-zips.ts`:
       - Import the Houston ZIP data from `./data/houston-zips.json`
       - Import `createClient` from `@supabase/supabase-js`
       - Create a service-role Supabase client (same pattern as seed-admin.ts)
       - Define role cap multipliers:
         ```typescript
         const BASE_CAPS: Record<string, number> = {
           agent: 5, lender: 3, inspector: 2,
           title_company: 2, appraiser: 2, contractor: 3
         }
         const TIER_MULTIPLIERS: Record<string, number> = {
           premium: 1, standard: 1.5, suburban: 2
         }
         ```
       - For each ZIP in the dataset, for each of the 6 professional roles:
         - Calculate `total_cap = Math.ceil(BASE_CAPS[role] * TIER_MULTIPLIERS[tier])`
         - Upsert into `zip_seats` table with: zip_code, role, total_cap, phantom_count (0), tier, neighborhood
         - Use `onConflict: 'zip_code,role'` for idempotent re-runs
       - Log progress: "Seeded {N} rows for {M} ZIPs"
       - Handle errors with clear messages

    2. Add `package.json` script: `"seed:zips": "npx tsx scripts/seed-zips.ts"`

    3. Run the seed script: `npm run seed:zips`

    4. Verify seed data by querying the database:
       - Total row count in zip_seats
       - Sample Premium ZIP (e.g., 77006) should have agent cap = 5
       - Sample Standard ZIP should have agent cap = 8
       - Sample Suburban ZIP should have agent cap = 10
       - All 6 roles should exist for each ZIP
